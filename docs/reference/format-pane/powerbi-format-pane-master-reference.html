Consolidated HTML reference updated

The left pane now combines the shared General properties applicable to every visual with visual-specific panes for Donut, Pie, Funnel, Treemap, Bar / Stacked Bar, Clustered Bar, Clustered Column, Column / Stacked Column, 100% Stacked Bar, and 100% Stacked Column. Controls are represented using the same interaction type seen in Power BI.

Color controls are functional. Clicking a swatch opens the browser color palette. Dropdowns retain captured options where you provided them. Font dropdowns currently include a small default set; more Power BI font options can be extended later.
