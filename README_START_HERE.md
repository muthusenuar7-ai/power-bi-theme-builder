# Datacense Power BI Theme Studio — Starter Kit

This folder contains the AI guidance files and phased prompts for building the Datacense Power BI Theme Studio from scratch.

Use order:
1. Create the Next.js project.
2. Copy your uploaded files into `docs/reference/`.
3. Copy these starter kit files into the project root.
4. Start Claude Code.
5. Use the skills/prompts phase by phase.
6. Use Codex for final review.

Important:
- Do not paste the entire old HTML into React as one file.
- Use the HTML as a UI/reference source only.
- Build phase by phase and run `npm run build` after every major phase.
